# House Management UI Design System

## Design Direction

The application uses an enterprise administration UI.

The design should feel:

- professional
- clean
- modern
- spacious
- trustworthy
- consistent
- easy to operate for staff

Avoid:

- excessive gradients
- excessive rounded cards
- playful colors
- unnecessary animations
- overly large typography
- consumer/social-media styling

# Buttons

Primary:

Blue background
White text

Secondary:

White background
Blue border
Blue text

Import:

Amber/orange background
White text

Danger:

Red

Buttons should have:

- icons
- appropriate spacing
- consistent height
- clear hover state
- disabled state

---

# Forms

Use:

- Bootstrap grid
- labels above fields
- consistent field heights
- clear validation messages
- required indicators
- textarea for descriptions
- select for status
- adequate spacing

Create/edit forms should generally use:

Row 1:
3 fields

Row 2:
Description

Row 3:
Actions

---

# Tables

Enterprise data tables should have:

- clear header
- subtle borders
- row hover
- status badges
- compact action buttons
- search
- pagination
- empty state
- loading state

---

# Modals

Use:

- clear title
- close button
- descriptive subtitle where appropriate
- clear footer actions
- loading state
- validation errors

Import modals should support:

1. Download template
2. Select/upload file
3. Preview
4. Import

---

# Notifications

Use toast notifications for:

Success:
green

Warning:
amber

Messages should be concise.
